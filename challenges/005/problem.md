# Day 005 - Find the divisors!

**Source:** [Codewars - Find the divisors!](https://www.codewars.com/kata/544aed4c4a30184e960010f4)

## Problem

Create a function that takes an integer and returns an array with all of the integer's divisors(except for 1 and the number itself), from smallest to largest. If the number is prime return the string '(integer) is prime'.

## Examples

| Input       | Output      |
|-------------|-------------|
| 12     | [2, 3, 4, 6] |
| 25    | [5] |
| 13 | "13 is prime" |
