# Day 004 - You're a square!

**Source:** [Codewars - You're a square!](https://www.codewars.com/kata/54c27a33fb7da0db0100040e)

## Problem

Given an integral number, determine if it's a square number.

## Examples

| Input       | Output      |
|-------------|-------------|
| -1     | false |
| 0    | true |
| 3 | false |
| 4 | true |
| 25 | true |
| 26 | false |
