# Day 009 - Decode the Morse code

**Source:** [Codewars - Decode the Morse code](https://www.codewars.com/kata/54b724efac3d5402db00065e)

## Problem

Implement a function that would take the morse code as input and return a decoded human-readable string.

## Examples

| Input       | Output      |
|-------------|-------------|
| ".... . -.--   .--- ..- -.. ." | "HEY JUDE" |
